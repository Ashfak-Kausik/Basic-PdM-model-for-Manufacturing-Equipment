These are the class_weight='balanced' results (SVM, RF, LR balanced on the base
learners), retained as the cost-sensitive baseline for reviewer comment R1.6.

Generated by src/run_baseline.py under the canonical config BEFORE
class_weight='balanced' was removed from SVM/RF/LR in src/config.py. Do not
regenerate or overwrite this directory by re-running src/run_baseline.py --
it now writes the unbalanced config's results to outputs/ directly. This
snapshot is a static copy, not reproducible from the current src/config.py
without reverting that change.

Under this config, OR-logic reached ~95.3% recall but its false-positive
count exploded (SVM ~190 FP, LR ~350 FP individually; 418 FP unioned into
OR-logic), collapsing precision to ~16% and specificity to ~83%. That
broke the paper's actual claim (high recall while specificity stays near
99.5%), which is why the balanced weighting was reverted for the main
pipeline. See DELTA_vs_paper.md in this directory for the full comparison
against the paper and the faithful reproduction as it stood at the time.

  figures/               -- confusion matrices + ROC curve, modified data (balanced-weights run)
